# Experiment 2: Gradients and Level Curves

## 1. Objective
The objective of this experiment was to understand how gradients relate to level curves, visualize their relationship, and see how gradients guide optimization in machine learning.

## 2. Loss Function
We used the following loss function:

\[L(w_1, w_2) = w_1^2 + 2w_2^2\]

The function produces elliptical level curves centered at the origin. The minimum loss is 0, occurring at \((0,0)\).

## 3. Understanding Level Curves
A level curve represents all parameter combinations that produce the same loss value. 

For example:

\[w_1^2 + 2w_2^2 = 6\]

Every point on this curve has a loss of 6. 

Moving along the same level curve does not change the loss. Moving towards curves with lower loss values improves the model's objective.

## 4. Understanding the Gradient
The gradient of our loss function is:

\[\nabla L = \begin{bmatrix} 2w_1 \\ 4w_2 \end{bmatrix}\]

The gradient points in the direction of the steepest increase in loss, while the negative gradient points in the direction of the steepest decrease.

## 5. Gradient Perpendicularity
The gradient is perpendicular to the level curve at the point where it is evaluated.

* The directional derivative along a level curve is zero because the loss remains constant as we move along it.
* Since the directional derivative is the dot product of the gradient and the direction vector, a zero result establishes that the two vectors are perpendicular.

## 6. Visualizing Multiple Gradients
We plotted gradient vectors at different parameter coordinates. 

The observations were:
* Gradient directions change depending on the parameter values.
* The gradient vectors point away from the minimum at the origin.
* Gradient magnitudes decrease as the parameters approach zero.
* At the minimum, the gradient becomes the zero vector.

## 7. Python Implementation
The following script was used to generate the coordinate grids, compute the loss levels, calculate vectorized gradients across multiple coordinates, and visualize the system using contour lines and vector fields.

```python
import numpy as np
import matplotlib.pyplot as plt

# 1. Generate grid values for the loss surface
w1 = np.linspace(-3, 3, 100)
w2 = np.linspace(-3, 3, 100)
W1, W2 = np.meshgrid(w1, w2)

# Calculate the loss surface heights
L = W1**2 + 2 * W2**2

# 2. Set up the plotting canvas
fig, ax = plt.subplots(figsize=(10, 6))

# Plot contour lines (Level Curves)
contour = ax.contour(W1, W2, L, levels=10, cmap='viridis')
ax.clabel(contour, inline=True, fontsize=8)

# 3. Define the specific evaluation points
points_w1 = np.array([1, -1,  1, -1, 2,   0.1, 0.2])
points_w2 = np.array([1,  1, -1, -1, 0.5, 0.1, 0.2])

# Calculate gradients using vectorized operations
gradient_w1 = 2 * points_w1
gradient_w2 = 4 * points_w2

# 4. Plot gradient vectors (using scale=15 to keep vector arrows within the bounds)
ax.quiver(
    points_w1,
    points_w2,
    gradient_w1,
    gradient_w2,
    color="red",
    angles="xy",
    scale_units="xy",
    scale=15,
    label="Gradient Vector (Steepest Ascent)"
)

# Plot point markers for clarity
ax.scatter(points_w1, points_w2, color='black', zorder=5)

# Formatting using proper Matplotlib LaTeX formatting
ax.set_xlabel(r"\(w_1\)")
ax.set_ylabel(r"\(w_2\)")
ax.set_title("Level Curves and Gradient Field Visualization")
ax.grid(True, linestyle='--', alpha=0.5)
ax.legend()

plt.show()
```

## 9. Connection to Machine Learning
Gradient descent uses the negative gradient to update model parameters:

$$w_{\text{new}} = w_{\text{old}} - \alpha \nabla L$$

* The learning rate ($\alpha$) controls the step size, while the gradient determines the direction and magnitude of the update.
* As the gradient becomes smaller near the minimum, parameter updates also become smaller when the learning rate is constant.

This is fundamental to understanding how machine learning models learn by minimizing their loss functions.

## 10. Conclusion
This experiment demonstrated how level curves and gradients work together during optimization. I learned that the gradient is perpendicular to a level curve, points towards increasing loss, and guides gradient descent in the opposite direction.

Understanding this relationship provides a mathematical foundation for studying optimization algorithms and neural network training.
